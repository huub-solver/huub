# Huub CLI

<p align="center">
  <img
    src="https://huub.solutions/favicon.svg"

    height="350px">
</p>

The `huub-cli` crate contains a command-line interface for the [`huub`](https://crates.io/crates/huub) solver framework.
It installs the `huub` executable.
See [huub.solutions](https://huub.solutions) for documentation and project information.

Most real-world CLI usage also requires additional assets that are shipped with the binary releases.
For complete setups, use the release artifacts from the [GitHub releases page](https://github.com/huub-solver/huub/releases).

The executable can be used as a MiniZinc solver backend.
Use `huub --help` to see available options.
